**Spec ruling:** the acceptance brief describes a zero-slide initial Google Slides document, while Google documents provider-generated default slide IDs for newly created presentations ([presentation overview](https://developers.google.com/workspace/slides/api/guides/overview)). The offline candidate assumes exactly one starting slide and reuses it, but caller assertions are unverified and are never sufficient to dispatch. It issues no deletions. A future route must independently observe the full presentation inventory/revision and reconcile this initial-state requirement before any write; until then the candidate is not executable.

The Slides and Canva input values are caller assertions. Their output includes `preconditions_authoritative: false`; only a future authenticated runtime observer can upgrade these facts. No live connection or app effect was performed in this work.
