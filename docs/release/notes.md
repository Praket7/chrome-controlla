# Chrome Controlla 0.1.0 release-candidate notes

This is a local, host-specific candidate, not a published release. It includes the Chrome MV3 selected-tab bridge, local stdio MCP server, durable bounded workflow jobs, guarded direct/shared-tab input, extraction, and principal/session-scoped file-selection artifacts.

The candidate is fixture- and host-package-verified only. Slides, Canva, and CapCut Web persistence; live extension pairing; external client acceptance; authenticated remote transport; broad platform/mode qualification; and comparative performance are not established. Trusted-local JavaScript remains opt-in and is not an OS security boundary.

See [support matrix](support-matrix.md), [rollback](rollback.md), [master guide](../MASTER_GUIDE.md), and [known blockers](../blockers.md) before testing.
