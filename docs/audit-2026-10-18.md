## Route and research decisions

Use a short `route_selection`: selected source tab and identity probe, rejected candidates with reason codes, then action. When no existing destination tab safely matches, create a new tab in the selected authorized window. With several attached source tabs, supply the exact source `chrome_tab_id`; ambiguity stops before dispatch. When no attached source passes the identity probe, select and pair an exact stable tab in the intended window before opening; do not infer a source from title or index. This follows Chrome's [Tabs API](https://developer.chrome.com/docs/extensions/reference/api/tabs) and [Tab Groups API](https://developer.chrome.com/docs/extensions/reference/api/tabGroups); frozen tabs' execution restriction is documented by Chrome. Private headless uses [Chrome Headless mode](https://developer.chrome.com/docs/automation-and-testing/headless). [Playwright MCP](https://github.com/microsoft/playwright-mcp) and [Chrome DevTools MCP](https://github.com/ChromeDevTools/chrome-devtools-mcp) were reviewed as public comparison surfaces; their existence is not speed evidence. Exa, Parallel Search, alphaXiv and SciSpace were consulted for implementation and agent benchmark patterns; discovered research was not treated as runtime qualification.
